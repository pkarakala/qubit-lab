## Overlap of the two cat basis states

`cat.coherent_overlap`

```latex
|\langle \alpha | -\alpha \rangle|^2 = e^{- 4 \alpha^{2}}
```

Valid when: Exact for coherent states.

- gerry2005, Ch. 3 (coherent states), Ch. 7 (cat states) (textbook).

## Wigner function of a coherent state

`cat.wigner_coherent`

```latex
W_{|\alpha\rangle}(x, p) = \frac{2 e^{- 2 p^{2} - 2 \left(- \alpha + x\right)^{2}}}{\pi}
```

Valid when: Exact. Convention beta = x + ip, hbar = 1/2.

- gerry2005, Ch. 3 (coherent states), Ch. 7 (cat states) (textbook).

## Wigner function of the even cat |C+>

`cat.wigner_even_cat`

```latex
W_{|\mathcal{C}^+_\alpha\rangle}(x, p) = \frac{\frac{4 e^{- 2 p^{2} - 2 x^{2}} \cos{\left(4 \alpha p \right)}}{\pi} + \frac{2 e^{- 2 p^{2} - 2 \left(- \alpha + x\right)^{2}}}{\pi} + \frac{2 e^{- 2 p^{2} - 2 \left(\alpha + x\right)^{2}}}{\pi}}{2 + 2 e^{- 2 \alpha^{2}}}
```

Valid when: Exact for real alpha. The cosine fringes near the origin carry the parity.

- gerry2005, Ch. 3 (coherent states), Ch. 7 (cat states) (textbook).

## Wigner function of the odd cat |C->

`cat.wigner_odd_cat`

```latex
W_{|\mathcal{C}^-_\alpha\rangle}(x, p) = \frac{- \frac{4 e^{- 2 p^{2} - 2 x^{2}} \cos{\left(4 \alpha p \right)}}{\pi} + \frac{2 e^{- 2 p^{2} - 2 \left(- \alpha + x\right)^{2}}}{\pi} + \frac{2 e^{- 2 p^{2} - 2 \left(\alpha + x\right)^{2}}}{\pi}}{2 - 2 e^{- 2 \alpha^{2}}}
```

Valid when: Exact for real alpha.

- gerry2005, Ch. 3 (coherent states), Ch. 7 (cat states) (textbook).

## Mean photon number of the even cat

`cat.even_cat_photon_number`

```latex
\langle n \rangle_{\mathcal{C}^+} = \alpha^{2} \tanh{\left(\alpha^{2} \right)}
```

Valid when: Exact. Tends to |alpha|^2 once |alpha|^2 > 2.

- gerry2005, Ch. 3 (coherent states), Ch. 7 (cat states) (textbook).

## Mean photon number of the odd cat

`cat.odd_cat_photon_number`

```latex
\langle n \rangle_{\mathcal{C}^-} = \frac{\alpha^{2}}{\tanh{\left(\alpha^{2} \right)}}
```

Valid when: Exact.

- gerry2005, Ch. 3 (coherent states), Ch. 7 (cat states) (textbook).

## Cat size when single-photon loss competes with two-photon dissipation

`cat.stabilized_photon_number`

```latex
|\alpha_\infty|^2 = \alpha^{2} - \frac{\kappa_{1}}{2 \kappa_{2}}
```

Valid when: Semiclassical. kappa_1 << kappa_2 |alpha|^2.

- catlab_hand_calcs, docs/hand_calcs/cat_steady_state.py (derived). Mean-field steady state of d<a>/dt, starting from lescanne2020 Eq. (1).

## Decay rate of the cat parity <P> under single-photon loss

`cat.parity_decay_rate`

```latex
\Gamma_{P} = 2 \alpha^{2} \kappa_{1}
```

Valid when: Two-photon dissipation dominates; |alpha|^2 > ~1.

- [mirrahimi2014](https://doi.org/10.1088/1367-2630/16/4/045014), Sec. 2, unnumbered text after Eq. (1) (peer_reviewed). Gives the flip rate kappa_1 |alpha|^2; <P> decays at twice that.

## Phase-flip probability rate

`cat.phase_flip_rate`

```latex
\Gamma_Z = \alpha^{2} \kappa_{1}
```

Valid when: Same as parity decay. <X> = 1 - 2 p_Z decays at 2 Gamma_Z.

- [mirrahimi2014](https://doi.org/10.1088/1367-2630/16/4/045014), Sec. 2, unnumbered text after Eq. (1) (peer_reviewed). That paper swaps the basis names and calls this error a bit-flip.
- [guillaud2019](https://doi.org/10.1103/PhysRevX.9.041053), Sec. II, unnumbered (peer_reviewed). Linear in |alpha|^2.

## Bit-flip rate ratio after adding Delta_n photons

`cat.bit_flip_suppression`

```latex
\frac{\Gamma_X(|\alpha|^2 + \Delta n)}{\Gamma_X(|\alpha|^2)} = e^{- 2 \Delta_{n}}
```

Valid when: Asymptotic, |alpha|^2 >~ 4. Prefactor depends on the noise model.

- [guillaud2019](https://doi.org/10.1103/PhysRevX.9.041053), Sec. II, unnumbered (peer_reviewed). Bit-flips are exponentially suppressed with 2|alpha|^2.
- [lescanne2020](https://doi.org/10.1038/s41567-020-0824-x), Fig. 3 (peer_reviewed). Measured: x4.2 per added photon (not e^2 = 7.4), saturating at 1 ms.

## Bit-flip rate caused by pure dephasing

`cat.bit_flip_rate_dephasing`

```latex
\Gamma_X^{(\phi)} = \frac{\alpha^{2} \kappa_{\phi}}{2 \sinh{\left(2 \alpha^{2} \right)}}
```

Valid when: kappa_phi << kappa_2. Falls as e^{-2|alpha|^2}, like the loss-induced rate.

- [mirrahimi2014](https://doi.org/10.1088/1367-2630/16/4/045014), Sec. 2, unnumbered display (peer_reviewed). Called a phase-flip there, because that paper swaps the basis names.

## Kerr cat amplitude

`cat.kerr_cat_amplitude`

```latex
\alpha = \frac{\sqrt{\epsilon_{2}}}{\sqrt{K}}
```

Valid when: H = -K a+^2 a^2 + epsilon_2 (a+^2 + a^2); |+-alpha> are degenerate eigenstates.

- [grimm2020](https://doi.org/10.1038/s41586-020-2587-z), Eq. (1) (peer_reviewed). The Kerr-cat Hamiltonian.
- catlab_hand_calcs, docs/hand_calcs/kerr_cat_amplitude.py (derived). Classical fixed points of Eq. (1).

## Josephson plasma energy

`transmon.plasma_frequency`

```latex
\hbar\omega_p = 2 \sqrt{2} \sqrt{E_{C}} \sqrt{E_{J}}
```

Valid when: Small-phase expansion of the cosine.

- [koch2007](https://doi.org/10.1103/PhysRevA.76.042319), Eq. (2.11), leading term (peer_reviewed).

## Energy of level m (Duffing oscillator approximation)

`transmon.level_energy`

```latex
E_m = 2 \sqrt{2} \sqrt{E_{C}} \sqrt{E_{J}} \left(m + \frac{1}{2}\right) - \frac{E_{C} \left(6 m^{2} + 6 m + 3\right)}{12} - E_{J}
```

Valid when: E_J / E_C >> 1, low levels m.

- [koch2007](https://doi.org/10.1103/PhysRevA.76.042319), Eq. (2.11) (peer_reviewed).

## Qubit transition energy E_01

`transmon.qubit_frequency`

```latex
E_{01} = 2 \sqrt{2} \sqrt{E_{C}} \sqrt{E_{J}} - E_{C}
```

Valid when: E_J / E_C >> 1.

- [koch2007](https://doi.org/10.1103/PhysRevA.76.042319), Eq. (2.11), m=1 minus m=0 (peer_reviewed).

## Anharmonicity E_12 - E_01

`transmon.anharmonicity`

```latex
\alpha_{\mathrm{tr}} = - E_{C}
```

Valid when: E_J / E_C >> 1. Sets how fast a gate can be without leaking to level 2.

- [koch2007](https://doi.org/10.1103/PhysRevA.76.042319), Eq. (2.12); definition Eq. (2.10) (peer_reviewed).

## Charge dispersion of level m, E_m(n_g=1/2) - E_m(n_g=0)

`transmon.charge_dispersion`

```latex
\epsilon_m = \frac{\left(-1\right)^{m} \sqrt{2} \cdot 2^{4 m + 5} E_{C} \left(\frac{E_{J}}{2 E_{C}}\right)^{\frac{m}{2} + \frac{3}{4}} e^{- \frac{2 \sqrt{2} \sqrt{E_{J}}}{\sqrt{E_{C}}}}}{\sqrt{\pi} \Gamma\left(m + 1\right)}
```

Valid when: Asymptotic in E_J / E_C. Why transmons shrug off charge noise.

- [koch2007](https://doi.org/10.1103/PhysRevA.76.042319), Eq. (2.5); definition Eq. (2.4) (peer_reviewed).
